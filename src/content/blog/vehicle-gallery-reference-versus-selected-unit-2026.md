A product gallery can help a buyer choose a body style, seating layout or model family. A photograph of a particular used car serves a different purpose: it should correspond to that vehicle's reference. Keep those uses clear when moving from browsing to an order discussion.

## Label what the gallery represents

For a catalogue model, say when configurations, colours or accessories vary. A photograph of a cargo version should not silently become evidence for a passenger version. If a caption is missing, retain that gap rather than guessing from a similar image elsewhere.

For an individual used vehicle, preserve the listing reference and the original matching photo set. Exterior and interior images should belong to the same unit. Reusing that verified set avoids unnecessary rework, while changes to the selected vehicle should trigger a new comparison.

## Separate visible features from unverified claims

A photograph can show an arrangement or a visible accessory. It cannot, by itself, establish accident history, battery health, ownership, destination eligibility or what is included in a quotation. Those points require the applicable records or order checks.

Keep the source and model reference with images used in a buyer brief. Do not assemble a convincing-looking gallery from different vehicles, replace missing views with a similar model or describe a generic illustration as an actual selected unit.

## Use the right evidence at the right step

During model selection, an accurately labelled catalogue may be sufficient to compare intended uses and layouts. Before confirming an individual vehicle or a specific production configuration, match the proposal to the relevant reference, specification and supporting records.

If the buyer changes the model, version or vehicle, update the matched materials before continuing. Existing images do not need to be remade merely because the discussion resumed on a later date.

Provide UCarsea with the model or vehicle reference, destination and quantity. We can organise the existing materials and identify only the evidence gaps that affect the selected order.
