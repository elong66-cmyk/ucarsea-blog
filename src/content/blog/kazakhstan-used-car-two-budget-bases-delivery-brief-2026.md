“My budget is $15,000” can describe two different orders: a vehicle costing $15,000 before transport, or a complete delivered purchase within $15,000. For Kazakhstan-bound used-car enquiries, resolve that difference before comparing listings.

## Name the two budget bases

Record a vehicle-only ceiling and a separate delivered-cost ceiling, both with a currency. If you only know one, say which. A seller should not silently subtract an assumed logistics allowance or present a vehicle-only number as an all-in purchase cost.

Do the same for the delivery point: name the final city and requested handover location. A border arrival, a logistics terminal and a delivered vehicle are different scopes. A route proposal is not a confirmed service or promised transit time.

## Keep specification attached to each price

For each option, record model year, exact trim, fuel type, mileage, steering configuration and disclosed condition. Confirm the actual vehicle identity privately before the commercial decision. Comparing only year and brand can hide different powertrains, equipment or repairs.

Import eligibility, registration, valuation and any applicable payments require current, vehicle-specific checks with the relevant authorities and local specialists. This guide does not state a Kazakhstan duty rate, exemption or automatic registration approval.

## Ask for a clearly bounded quotation

Request these fields in the quote:

- The exact unit or clearly identified sourcing specification.
- Currency, named delivery term and place.
- Vehicle cost and separately identifiable origin, transport and destination items.
- Which figures are confirmed, which are estimates and which are excluded.
- Inspection evidence, unresolved eligibility questions and responsible parties.
- Validity period, payment conditions and the event that triggers each obligation.

An empty line should read “not yet confirmed,” not zero. A placeholder freight figure should never be treated as a booked rate.

## Use one worksheet for supplier comparisons

| Question | Option A | Option B |
|---|---|---|
| Same specification and condition? | Confirm or explain difference | Confirm or explain difference |
| Same delivery endpoint and cost scope? | State boundary | State boundary |
| Current unit and inspection evidence? | Reference and date | Reference and date |
| Local eligibility checked? | Evidence or unresolved | Evidence or unresolved |
| Next decision? | Named action and owner | Named action and owner |

This comparison is useful even when neither option is ready for a deposit: it shows which question must be answered next. Do not declare a resale margin until the full cost scope and the intended local sale assumptions have been reviewed.
