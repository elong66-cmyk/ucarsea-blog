A sample can help a dealer assess a vehicle's layout, finish and intended use. It does not automatically define every detail of a later production order. A useful next step is to write down what was evaluated and what the next order must include.

## Identify the sample precisely

Use a model name together with a configuration reference. Record the battery option, charger, seating or cargo arrangement and the accessories actually supplied. Keep dated photographs with the reference so a similar-looking model is not substituted in the comparison.

Separate an observation from a supplier statement. A photograph may show a connector or a rear rack; it does not establish battery capacity, transport documentation or a destination's permission to use that vehicle. A brief test ride also does not establish long-term reliability.

## Create a separate production specification

List the agreed configuration for the later order. Mark each item as unchanged from the sample, changed, or still to be confirmed. Changes to the battery, controller, charger, dimensions or packaging deserve their own line rather than a broad phrase such as “same quality as the sample.”

For a dealer order, include the quantity by version and the accessories or spare parts included. Keep service responsibilities and the documents required for the actual destination with the order record. A sample review should not be described as a blanket certification or a guaranteed delivery outcome.

## Resolve differences before confirmation

If the proposed production version differs, compare the written revision with the original sample record. Confirm the revised scope before treating the sample price or specification as the production agreement.

For a UCarsea model discussion, provide the exact model, intended use, destination and expected quantity. These details support a model-specific review; they are not an order or a final quotation.
